# 更新日志

## [2.3.3] — 2026-10-26

### 系统要求与文档

- 明确最低支持 **Windows 10 / 11**。这两个系统自带 WebView2 Runtime，应用不再为缺少 WebView2 的旧版 Windows 做主动适配或验收。
- 安装器仍保留 `downloadBootstrapper` 联网引导作为兜底；缺少运行时时若无法联网，不属于支持范围。
- 同步 `package.json`、`Cargo.toml`、`tauri.conf.json` 版本号至 2.3.3。
- 修正测试文档中滞后的版本号（此前仍写 2.0.1）与许可门禁状态（`licenses:release` 现已通过）。
- 手动验收清单与未验收范围按实际验证结果更新为已完成。

### 内部命名统一为 GrabMeta

- 前端包名 `yt-dlp` → `grabmeta`；Rust crate `yt-dlp-gui-cn` → `grabmeta`，库 `yt_dlp_gui_lib` → `grabmeta_lib`。主 EXE、窗口标题和安装包名此前已是 GrabMeta，本次仅清理内部残留。
- 自动更新偏好键 `ytdlp.auto-update-check` → `grabmeta.auto-update-check`。**旧键会被自动迁移**，已关闭自动更新的用户升级后不会被动重新开启。
- 工具安装的暂存与备份目录前缀改为 `.grabmeta-*`；旧备份目录 `.ytdlp-gui-bin-backup` 仍可被读取，安装中断的机器不会丢失 `bin/`。
- 应用标识 `com.ssk-shandm.ytdlp-gui` → **`com.ssk-shandm.grabmeta`**，与产品名完全统一。因标识决定 `%APPDATA%` 配置目录，应用启动时会把旧目录的 `settings.json` 自动迁移一次，升级用户的下载目录与偏好不会丢失。
- 自动更新器同步校验新标识，测试版安装包（`.install-test`）仍无法启动正式版更新。

## [2.1.0] — 2026-10-09

Windows x64 NSIS 功能版本。安装包不再内置 yt-dlp / FFmpeg，首次启动时按需从上游下载。

### 许可与依赖

- `number-precision` 上游 1.6.0 缺少完整版权通知，改由项目自有 MIT 实现（`frontend/vendor/number-precision`）替代，行为与上游保持一致。

### 更新链路

- 桌面端检查 Release 与下载安装包统一使用原生 HTTPS 客户端，初始化完成后再启动自动检查，保持本地代理/系统网络设置一致。
- 自动更新只接收本项目 GitHub Release 的 x64 NSIS 包；校验 GitHub 资产 SHA-256，缺失、格式错误或不匹配时停止安装。哈希不是发布者签名，不要求购买 Windows 签名证书。
- 限制更新重定向到受支持的 GitHub HTTPS 主机；下载失败清理临时文件并解除任务更新锁，安装器成功启动后才发送安装开始事件。

### 下载速度与稳定性

- 媒体 DASH/HLS 分片默认 8 路并发，可在“内容处理 → 主要用法”选择 1 / 4 / 8 / 16 路；旧设置自动补齐默认值，保留下载目录和重试次数。
- 上游工具大文件支持最多 4 路 Range 下载与缓冲写入，不支持分段的服务器复用单路响应；保留 HTTPS、大小和 SHA-256 校验。
- 工具安装显示实际传输速度及预计剩余时间；传输失败及时结束其他连接，取消后等待清理和取消请求结束才能重试。
- 不设置应用下载限速；普通直链、目标站点限流和代理线路不保证因分片并发而提速。

### 按需获取第三方工具

- GUI 安装包不再捆绑 yt-dlp / FFmpeg / ffprobe；首次运行可选择 BtbN LGPL 基础版或 GPL 完整版，从 HTTPS 上游下载并校验。
- 基础版可在“关于”页升级为完整版；失败或取消保持已有工具不变，并保存实际工具版本、来源和许可记录。

### 本地 VPN / 代理

- “关于 → 设置”新增本地 VPN 客户端代理地址，可填写 HTTP / SOCKS5 / SOCKS5H 回环地址。启用后链接解析、媒体下载、工具下载和更新请求使用该代理；程序不负责安装或启动 VPN。
- 代理设置默认关闭；关闭时继续使用原有系统 / 环境网络配置。

### 测试与 Git 忽略

- 真实工具下载烟测默认收到有效传输数据后取消，不再等待工具完整下载；完整安装测试使用 `--full` 显式开启。
- PNG 原始图稿、截图、媒体下载和本地安装测试证据加入 Git 忽略；Tauri 打包必需的图标仍保留。

### 项目整理

- 移除不参与新版构建的 Python/Eel、Docker 和 pnpm 归档；旧源码仍可通过 Git 标签 `v2.0.1` 查看。
- 清理未引用的示例计数器、测试图片、写入探测文件、重复图标及非 Windows NSIS 图标。
- 删除不用的 Element Plus 图标、Less 和重复的直接 ESLint parser 依赖，保留使用中的 Sass 及 TypeScript/Vue 工具链。
- 清理本地旧 PyInstaller 产物、Python 环境/缓存、临时工具压缩包和 1.1.0/2.0.0 安装包；保留当前安装包、下载工具、原始图稿及新版构建缓存。
- 更新项目结构、构建和迁移文档，补充文件维护规则及资源/文档链接回归测试；已发布的 2.0.1 安装包保持不变。

### 历史本地开发工具整理

- 使用 FDM 下载并替换为 Gyan FFmpeg Essentials 9.0.2 Windows x64 静态构建。
- 保留 yt-dlp 作为核心下载工具；FFmpeg / FFprobe 只承担媒体合并、转封装和后处理，不再保留过时的完整版下载入口。
- 更新工具预检、构建文档、第三方哈希记录和后续发布计划；当前 v2.0.1 已发布安装包未重新打包。

### 已知限制

- 干净 Windows（未安装 WebView2 Runtime）的安装、联网引导、断网和标准用户场景尚未验收。
- 从 2.0.1 覆盖升级到本版本的流程尚未在独立环境验收。
- 安装包未签名；SmartScreen 可能提示。

### 发布与仓库信息

- 新增用户向发布说明模板，后续公开 Release 不再包含内部验证、测试或构建结果。
- 将 v2.0.1 发布说明调整为更新内容、下载与安装、使用须知和文件信息，保留真实安装包大小与 SHA-256；不重发安装包。
- 补充 README 的中文版视频下载器介绍，便于了解项目用途。

## [2.0.1] — 2026-10-06

Windows x64 NSIS 修复版本，已发布到 GitHub Release。

- 版本统一升至 2.0.1，终端启动信息使用配置版本号。

## [2.0.0] — 2026-10-06

发行状态：代码与版本标签已推送，Windows x64 NSIS 安装包通过 GitHub Release 公开发布。发布说明采用显式 UTF-8 并回读校验；第三方分发材料和安装/覆盖升级验收仍未完成全部审核，详见 TESTING.md 和 THIRD_PARTY.md。

### 界面优化

- 封面初始与重置状态改为空白占位，支持分析中反馈和加载失败提示。
- 统一侧栏、页面标题、主内容区、卡片间距与响应式布局；移除固定 50% 的示例进度，展示实际任务统计。
- 新增页面切换、导航与按钮悬停、卡片反馈、封面加载动效，并尊重系统“减少动画”偏好。
- 新增“关于”页；最终精简为“项目基本信息”和“设置”两部分，信息仅保留版本号、版权、MIT 许可与项目仓库。
- 移除“本地桌面工具”、侧栏品牌图标/名称/副标题及“开源 · 本地运行”，收紧导航顶部留白。
- 桌面端从 GitHub Releases 检查正式版本，支持“关于”页手动检查和启动时自动检查；更新时下载并启动文件名以 `-setup.exe` 结尾的 NSIS 安装包。活动任务会延后安装，浏览器预览、开发版和便携版不执行自动安装。
- 由根目录“视频下载工具图标设计.png”生成 1024px RGBA PNG，并生成多尺寸 Windows ICO 与 Tauri 图标集，供 EXE 构建使用。
- 关于页使用原生浏览器打开项目链接，权限仅允许三个预设项目 URL。新增 UI 浏览器烟测。

### 新增

- Tauri 2 / Rust Windows 桌面入口与当前用户 NSIS 安装配置。
- 原生目录选择、设置持久化、本次运行任务列表和任务取消。
- 最多 4 个并发任务、解析/下载超时、进程输出与退出清理。
- Rust 单元测试、前端状态/配置测试、真实 WebView2 桌面烟测和打包工具预检。
- 开发、架构、构建、迁移、测试、第三方工具说明文档。

### 变更

- 保留 Vue 前端，将 Python/Eel 通信替换为 Tauri IPC。
- 更新 Vue、Vite、Vue 插件、类型检查和 ESLint 工具链，移除 ANSI-to-HTML 与旧 ESLint 配置依赖；本地 npm audit 报告 0 漏洞。
- 外部 yt-dlp / FFmpeg 作为应用资源分发，不再用 PyInstaller 打包应用层。
- 详细项目文档统一放入 docs；删除过时的 Python/Eel、Docker 使用指南及重复的 UI 改进、PR 和工作总结，按用途整理文档索引。
- 旧 Python/Eel、Docker 和 pnpm lock 移到 legacy/python-eel；当前依赖统一由 npm 管理。
- 终端改为纯文本渲染，并限制内存中日志与结束任务记录数量。

### 修复

- 封面下载误传目录而非视频链接。
- 重试次数的默认值、类型和分支逻辑。
- 解析失败/陈旧响应导致的加载状态和链接标记问题。
- 下载任务缺少统一错误结果和子进程生命周期管理。
- HTTP 封面在 CSP 下的展示；目录和重试设置保存使用补丁队列，避免互相覆盖。

### 本地验证

- Windows x64 NSIS 安装包构建成功，约 110.24 MiB。
- 前端 19 项（含自动更新与多尺寸图标校验）、UI 浏览器烟测、Rust 10 项测试通过；构建、ESLint、Rust 格式与 Clippy 检查通过。
- 真实桌面烟测验证六种下载模式、Vue 解析与封面、中文路径、并发限制、取消和正常退出进程清理。
- 安装/升级/卸载、干净机、外部站点和发行许可尚待验收；完整范围见 TESTING.md。

### 已知限制

- 当前只验证 Windows x64；不提供其他平台安装包。
- 自动更新要求发布者上传文件名以 `-setup.exe` 结尾的 Windows NSIS 安装包；当前仅适用于已安装的 Windows x64 当前用户版本。
- WebView2 缺失时安装器需要网络；安装包尚未配置签名。
- 第三方二进制许可和正式发布验收需要独立审核。
